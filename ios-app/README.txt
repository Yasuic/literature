Literature Card Game for iPhone
===============================

This folder is the complete Xcode project for the iPhone app. The game itself is in www/
and is copied into ios/App/App/public/ for the app.

With a Mac:     open ios/App/App.xcodeproj in Xcode.
Without a Mac:  upload this folder to a private GitHub repository and use the
                "Build iPhone app" workflow (cloud-build-workflow.yml).

Follow the step-by-step checklist from Claude for the full process.
